# Changelog

All notable SDK changes are recorded here. Versions follow semantic versioning.

## 1.0.0 - Unreleased

- Added deterministic host-device discovery through `cmi::Core::discover()`.
- Added the installed `cmi-play` reference and diagnostics CLI.
- Added standalone build presets, package-consumer qualification, and platform CI.
- Made the shipped Channel script sample-only by default.

The release remains unreleased until production USB identifiers and the
first macOS, Ubuntu x86_64, and Rockchip ARM64 hardware records are complete.
